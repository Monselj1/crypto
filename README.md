# Crypto Exchange Rate App

This app allows users to select a cryptocurrency and a traditional currency to view the real-time exchange rate.

## How to Use

1. Open `index.html` in your browser.
2. Select a cryptocurrency (e.g., Bitcoin).
3. Select a traditional currency (e.g., USD).
4. Click "Get Exchange Rate" to view the current rate.

No installation required. Just open the file in any modern browser.
